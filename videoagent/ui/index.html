FANPAGE FACEBOOK

Kết nối & quản lý Fanpage

Lấy User Access Token trên Graph API Explorer → dán vào đây → app lấy danh sách Fanpage và Page Token tương ứng.

① USER ACCESS TOKEN
  1. Mở Graph API Explorer (nút bên dưới), chọn Meta App của bạn.
  2. Ở User or Page chọn User Token, thêm quyền: pages_show_list pages_read_engagement pages_manage_posts — dùng Quảng cáo Facebook thì thêm ads_read ads_management.
  3. Bấm Generate Access Token, đăng nhập và cho phép các page cần dùng.
  4. Copy Access Token (bắt đầu bằng EAA…) và dán vào ô dưới.
② APP META tuỳ chọn

Token lấy từ Graph API Explorer chỉ sống ~1–2 giờ. Nhập App ID + App Secret của đúng app đã chọn trong Explorer để app tự đổi sang token dài hạn (~60 ngày) — Page Token cũng dài hạn theo.

③ Chưa có fanpage

THƯ VIỆN TEMPLATE

Template

Chọn template để dùng ngay: HTML động (app tự dựng) hoặc Video AI (Grok / Gemini).

HƯỚNG DẪN

Bắt đầu nhanh

  1. Chọn Provider AI ở mục “AI tạo nội dung & hình ảnh” — Gemini / Grok / Dola Browser (đăng nhập 1 lần bằng nút Đăng nhập), Gemini API (nhập API key trong Cài đặt) hoặc Offline để thử.
  2. Chọn Thể loại & Template. Template HTML động do app tự dựng hình; template Video AI · Grok / Gemini nhờ AI tạo video như quay thật.
  3. Nhập nội dung (với template HTML) hoặc điền các biến trong thẻ Video AI (với template AI). Có thể đính kèm ảnh sản phẩm, nhân vật, layout.
  4. Bấm “Tạo video →” và theo dõi ở tab Tiến trình. Video xong nằm trong Thư viện video.
  5. Trong Thư viện: Chi tiết để xem từng cảnh, sửa HTML và Render lại (template HTML).
